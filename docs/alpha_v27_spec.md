## 网络层（每 21 交易日重建，窗口 120 日）

三张网络，均先剔市场 beta + 申万一级行业均值取残差：

1. **价格网络**：残差收益相关，top-5
2. **双确认网络**：价格相关与资金流相关**均进 top-30** 才连边，再取 top-5
3. **转移熵有向网络**：相关筛 top-30 候选 → 逐边算 TE(j→i)（状态离散 {1,0,−1}，3×3×3 计数）→ 取 TE 最高 5 条
   - 与价格网络邻居**重合率仅 16.9%**，是真正不同的关系

## 打分层：三块 40/40/20

### 锚块 40% —— 五个锚的秩均值

| 锚 | 定义 |
|---|---|
| 价格 gap | (邻居 20 日动量加权均值 − 自身) / (vol20×√20) |
| zspread | 配对归一化价差 z 的 经典配对 softmax 聚合 |
| 双确认 gap | 同上，用双确认网络 |
| TE gap | 同上，用转移熵有向网络 |
| ROE gap | 自身 ROE − 邻居 ROE 加权均值 |

### 行为块 40% —— 两个逐笔特征（前 5 日）

- **−扫单卖占比**：单笔主动卖吃掉 ≥3 个对手单的金额 / 总成交额
- **−卖单平均规模**：主动卖总额 / 主动卖母单数

机制：**扫单 = 恐慌（可买），拆单/大额 = 计划性撤退（不可买）**

### 结构块 20% —— 两个 0/1 判断

- 股价 ≥ 2 元（面值退市螺旋）
- ΔROE 未恶化（新披露财报 ROE 环比不在最差 1/3）

## 选股与组合

- 硬剔：停牌 / 当日封涨停 / ST / 活跃域外
- 活跃域：过去 250 日收盘封涨停 ≥2 次
- N=200，权重 ∝ 综合分 + 0.3（单票 0.35–0.65%），满仓
- **组合约束（2026-08-31 采纳，见 `docs/robustness_and_weighting.md` 路线 B）**：
  个股上限 1%（防御性，现行不绑定）+ 行业偏离带 ±5%（相对活跃域等权分布），
  投影梯度求解。代价 −0.18pp 超额、IR 持平，属治理性改进。
  ⚠️ 风格敞口带（±0.25σ）已判负：压一半 SIZE 敞口需付 6.1pp 超额。
- 缓冲带：排名跌出前 600 才卖（停牌/跌停顺延）
- 周频（每 5 个交易日）
