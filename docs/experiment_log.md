# peer-anchor-microstructure-alpha
**同伴锚 × 微观行为 —— A股活跃中小盘错价修复选股策略**

起点: 四篇论文(图注意力网络类方法)
的共同经济内核 —— 构建股票关联网络, 用邻居信息做跨股预测。

经40轮实证演化后的实际形态(v27):
**在活跃中小盘域内, 用五个"同伴锚"识别相对兄弟股的错价, 再用逐笔成交行为区分
"散户恐慌抛售(可买)"与"知情资金撤离(不可买)", 周频持有200只多头组合。**
消融显示微观行为块贡献最大(-5.4pp), 同伴锚为冗余互补结构, 二者缺一不可。

## 数据
- 日频 OHLC/停牌/涨跌停: ${STOCK_ROOT}/price/price_daily (2014-01~2026-08, ~5200只)
- 收益 = close/pre_close - 1 (pre_close 复权口径, 自动处理除权)
- ST: info/st_info; 行业: info/industry (sw_l1 月度快照, PIT); 流通市值: fundamental/valuation
- 缓存: cache/daily_grid.npz, st_grid.npz, mcap_grid.npz, industry_monthly.pkl

## 网络构建 (scripts/02_network.py)
- 每 21 个交易日重建; 窗口 120 日; 每股 top-K=10 邻居
- resid 网络: 剔除市场(等权beta)+申万一级行业均值后的残差相关 (="超额联动")
- 对照: raw(只剔市场) / industry(同行业随机K个) / random(随机K个)
- top-10 邻居残差相关中位数 ~0.42 (A股联动极强)

## 信号 (scripts/03/05)
- peer_mom: 邻居过去20日动量的corr加权均值 (动量外溢, 经济关联动量 系)
- peer_gap: peer_mom - own_mom (邻居锚收敛)
- zspread: 论文公开预印本主信号, 配对归一化价差z-score 的 经典配对 softmax(-d) 聚合
- 周频(5日)调仓, 信号日过滤 停牌/触板/ST; 成本单边12.5bp
- 分段: dev 2015-01~2022-12, val 2023-01~2024-08-16, **test >= 2024-08-19 锁定未看**

## 结论(截至 v3, dev/val)
1. 表面结果: peer_gap 与 zspread IC≈0.05-0.06, 费后多空 Sharpe 1.5-2.5, val 不衰减。
2. **消融揭穿: 随机网络同样成立** → 头条数字的主体是 A 股自身20日反转, 不是网络alpha。
   - 纯反转基准 rev=-mom20: dev IC .061 / val .056
   - zspread 正交 rev 后: resid网络 .038 vs random .039 → 网络结构零增量
   - 纯动量外溢(peer_mom 正交 rev): resid dev FMB t=2.98, val t=0.97 → 微弱不可确认
3. 网络的真实贡献 = **锚的降噪**: peer_gap ICIR .57/.44 (dev/val) vs random .43/.34 vs rev .40/.32。
4. v3 检验锚质量单调性与配对收敛单调性 → 见 output/metrics_v3_anchor.json

## v40 多重检验校正 (metrics_v40_fdr.json) — 回应短期反转可交易性研究批评
